# Aviso de privacidad · Ethan · Aprende y Juega

*English version below.*

Esta app está hecha para niños, y la privacidad de cada niño es lo primero.

- **No recoge datos personales.** No pide nombre, correo, edad, fotos ni ubicación. No hay cuentas ni contraseñas.
- **No tiene anuncios, compras, chat ni enlaces a otras páginas.**
- **No se conecta a otros sitios.** La app tiene un bloqueo de seguridad (Content Security Policy) que solo le permite cargar sus propios archivos. No usa servicios de estadísticas ni de rastreo.
- **No usa la cámara.** El micrófono se usa en el estudio de grabación para adultos, detrás de un candado. Esas grabaciones se guardan en el mismo aparato y solo salen de ahí si un adulto las exporta.
- **Práctica de hablar:** el micrófono de los niños viene apagado. Si un adulto lo enciende, el niño puede oírse a sí mismo; esa grabación dura solo unos segundos en la pantalla y nunca se guarda.
- **Escritura libre:** lo que el niño escribe no se guarda ni se envía.
- **Lo único que guarda** son las estrellas, el nivel de cada lección, el idioma y el país elegidos, y todo queda en el mismo aparato. Un adulto lo puede borrar en *Para padres y maestros › Borrar el progreso*.
- **Voz del aparato:** cuando una frase no está grabada, la app usa solo voces que funcionan dentro del aparato, sin mandar texto a internet.

Nota sobre el sitio: si la app se publica en GitHub Pages, GitHub (el servicio que guarda la página) puede registrar datos técnicos de la visita, como la dirección IP, igual que cualquier sitio web. La app no agrega ningún rastreo propio. Si la instalan en el iPad, después funciona sin conexión.

Contacto: la autora, Rosa Laura Torres, en el perfil de GitHub donde está publicado este proyecto.

# Privacy notice (English)

- **No personal data is collected.** No name, email, age, photos or location. No accounts or passwords.
- **No ads, purchases, chat or links to other sites.**
- **No connections to other sites.** A Content Security Policy only lets the app load its own files. No analytics or tracking.
- **No camera.** The microphone is used in the grown-ups' recording studio, behind a lock. Those recordings stay on the device unless an adult exports them.
- **Speaking practice:** the children's microphone is off by default. If an adult turns it on, the child can hear themselves; that recording only lasts a few seconds on screen and is never saved.
- **Free writing:** what the child types is not saved or sent.
- **The only thing saved** is stars, lesson levels, language and country, all on the device. An adult can erase it in *For parents and teachers › Erase progress*.
- **Device voice:** for phrases not yet recorded, the app only uses on-device voices that don't send text to the internet.

Hosting note: when published on GitHub Pages, GitHub (the hosting service) may log standard technical visit data such as IP addresses, like any website. The app adds no tracking of its own. Once installed on an iPad, it works offline.
